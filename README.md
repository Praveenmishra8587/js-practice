# JavaScript Basics

This folder contains practice exercises and examples covering fundamental JavaScript concepts. Each file focuses on a specific topic to help you build a strong foundation in JavaScript.

## 📚 Topics Covered

### Variables & Data Types
- **`letvarconst.js`** - Differences between `let`, `var`, and `const` declarations
- **`dataTypes.js`** - JavaScript primitive data types (string, number, boolean, null, undefined, symbol, bigint)

### Operators
- **`mathematicaloperators.js`** - Arithmetic operations (+, -, *, /, %, **)
- **`mathoperator.js`** - Basic math operator examples
- **`comparisonOperator.js`** - Comparison operators (==, ===, !=, !==, <, >, <=, >=)
- **`incrementdecrement.js`** - Post and pre-increment/decrement operators
- **`ternaryoperator.js`** - Conditional ternary operator (? :)

### Control Flow
- **`Switchcase.js`** - Switch statement with case and default
- **`truthyfalsy.js`** - Truthy and falsy values in JavaScript

### Loops
- **`Loops.js`** - Different loop constructs (for, while, do-while, etc.)

### Arrays
- **`arrays.js`** - Array creation, indexing, and basic array operations
- **`arraymethods.js`** - Array methods (push, pop, shift, unshift, slice, splice)
- **`arrayiterations.js`** - Iterating over arrays (forEach, map, filter, reduce)
- **`reversearray.js`** - Array reversal techniques
- **`twoDimensionalArrray.js`** - Multi-dimensional arrays and nested array operations

### Objects
- **`objectconcepts.js`** - Creating and accessing objects
- **`objectiterations.js`** - Iterating over object properties
- **`objectparsing.js`** - JSON parsing and stringification
- **`objectreferences.js`** - Object reference behavior
- **`object refWithNull.js`** - Reference types and null values
- **`objecttest.js`** - Object testing and validation

### Functions
- **`functionconcept.js`** - Function declaration, expression, and arrow functions

### String Features
- **`templateliterals.js`** - Template literals with string interpolation

## 🎯 How to Use

1. Each file contains runnable JavaScript code examples
2. Open files in your browser console or Node.js environment
3. Read through the code and comments to understand the concepts
4. Try modifying the code and experimenting with different values
5. Use these files as a reference while learning JavaScript fundamentals

## 📖 Learning Path

**Recommended order to learn:**
1. Variables & Data Types
2. Operators
3. Control Flow

5. Arrays
